# 영상학습 관리 시스템 — 사용 매뉴얼

글만 읽어도 **어느 탭에 무엇이 있고, 무엇을 누르면 어떤 기능이 나오는지** 알 수 있도록 정리했습니다.  
**관리자 / 학생 / 강사** 각각 별도 섹션으로 구성합니다.

---

# 1. 관리자 페이지

**접속 경로:** `/admin` (관리자로 로그인 후 이동)

**상단 공통**
- **로고(학원명)** 클릭 → 대시보드(`/admin`)로 이동
- **대시보드** → 관리자 메인(학생·강사 목록, 영상 할당 등)
- **영상 관리** → 영상 등록·재생목록·배정·노출 설정
- **반 관리** → 반 추가/수정/삭제, 반별 진도, 반에 영상 일괄 배정
- **배정 목록** → 학생별 배정 영상 진도·시청 상세·우선학습·스킵방지·배정 해제
- **학생 화면** → 학생이 보는 화면(`/`)으로 이동
- **로그아웃** → 로그아웃 후 로그인 페이지로 이동

---

## 1-1. 대시보드 (`/admin`)

**상단 안내:** 학생 목록·영상 할당·모니터링. 학생·강사 등록, 학년·반 설정, 영상 배정, 퇴원·재원·리포트, 강사-학생 매칭.

### 목록 전환 (탭)
- **학생 목록** 클릭 → 학생 등록·학생 목록·영상 할당·퇴원/재원 화면
- **강사 목록** 클릭 → 강사 등록·강사 목록·강사별 학생 할당 화면

---

### [학생 목록 탭일 때]

#### ① 학생 등록 (맨 위 섹션)
- **이름** 입력, **비밀번호(4자 이상)** 입력 후 **학생 등록** 클릭 → 새 학생 계정 생성
- **enrollment_status 컬럼 추가 안내** 클릭 → 퇴원/재원 사용을 위한 DB 설정 안내 모달 열림  
  - 모달: SQL 복사, 앱에서 실행, Supabase 대시보드 링크, 닫기

#### ② 학생 목록 (아래 큰 섹션)
- **학생 이름 검색** 입력 → 이름 기준으로 목록 필터
- **재원생** 클릭 → 재원생만 표시
- **퇴원생** 클릭 → 퇴원생만 표시
- **정렬 기준:** **학년별** / **반별** → 목록 정렬 방식 변경

**각 학생 한 줄에 나오는 것**
- 이름, **학년 선택** 드롭다운, **반 선택** 드롭다운
- **영상 할당** 클릭 → 해당 학생이 선택되고, 아래에 **YouTube URL** 입력란과 **저장** 버튼, **등록된 재생목록/동영상에서 할당** 버튼이 나타남
  - URL 입력 후 **저장** → 그 영상을 해당 학생에게 배정
  - **등록된 재생목록/동영상에서 할당** 클릭 → 접기/펼치기. 펼치면 재생목록별·영상별 목록이 나오고, **재생목록 전체 할당** 또는 **할당** 클릭 시 해당 학생에게 배정
- **퇴원 처리** (재원생일 때만) → 확인 후 퇴원생으로 전환
- **재원 복귀** (퇴원생일 때만) → 재원생으로 복귀
- **완전 삭제** → 확인 후 계정 삭제
- **리포트 공유** 토글 → 켜면 학부모 리포트 URL이 보이고 **링크 복사**로 복사 가능

---

### [강사 목록 탭일 때]

#### ① 강사 등록 (맨 위)
- 이름·비밀번호 입력 후 **강사 등록** → 강사 계정 생성

#### ② 강사 목록
- **학생 이름 검색**으로 담당 학생 검색
- 각 강사 행: **할당된 학생 (N명)** 버튼 클릭 → 해당 강사의 담당 학생 목록 펼침/접기
- **학생 할당** 클릭 → **학생 할당 모달** 열림  
  - 모달: "담당할 학생을 선택하세요 (재원생만 표시)". 목록에서 체크박스로 여러 명 선택 후 **저장** → 해당 강사에게 선택한 학생 배정
- **강사 삭제** → 확인 후 강사 계정 삭제 (담당 학생의 강사 배정 해제됨)

---

## 1-2. 영상 관리 (`/admin/videos`)

**상단 안내:** YouTube URL 또는 재생목록으로 등록 후, 영상·재생목록 단위로 학생/반에 할당, 노출·주간과제를 학생·반별로 지정 가능.

### ① YouTube 재생목록으로 한 번에 등록 (맨 위 섹션)
- **재생목록 URL** 입력, **강좌 이름(선택)** 입력 후 **재생목록 가져와서 강좌로 등록** 클릭 → 재생목록이 강좌(재생목록)로 등록됨

### ② 단일 영상 등록
- **YouTube URL (단일 영상)** 입력, **제목(선택)** 입력 후 **영상 등록** 클릭 → 한 편 영상만 등록 (제목 비우면 자동 조회)

### ③ 등록된 재생목록 / 등록된 영상 (탭 + 목록)
- **등록된 재생목록** 클릭 → 재생목록(강좌) 단위로 목록 표시. 제목으로 검색 가능.
- **등록된 영상** 클릭 → 재생목록 없이 등록된 개별 영상만 표시. 제목으로 검색 가능.
- **등록된 영상 제목 일괄 업데이트** 클릭 → 등록된 영상 제목을 YouTube 기준으로 다시 가져옴

**검색창:** "제목으로 검색..." → 목록 필터

**영상이 있을 때 상단에 나오는 버튼**
- **전체 선택** 체크박스 → 현재 탭에 보이는 영상 전체 선택/해제
- **선택 항목 학생/반에 할당** (1개 이상 선택 시) 클릭 → **할당 모달** 열림  
  - 모달: "선택한 영상을 할당", 대상 N개 영상, **반으로 할당** / **학생 선택** 라디오, 우선 학습 체크, 반 선택 또는 학생 검색+다중 선택 후 **할당**
- **선택 항목 노출/주간과제 설정 (학생·반별)** 클릭 → **설정 모달** 열림  
  - 모달: 적용 대상(전체/특정 반/특정 학생), 노출·주간과제 옵션, **적용**
- **선택 항목 삭제** 클릭 → 확인 후 선택한 영상 삭제 (해당 영상 배정도 해제)

**재생목록 탭일 때**
- 각 재생목록 행: 왼쪽 화살표로 순서 변경, 체크박스(해당 재생목록 내 영상 전체 선택), **영상 보기 ▼** 클릭 → 아래에 영상 목록 펼침
- 펼친 목록의 각 영상: 체크박스, 썸네일, 제목(클릭 시 YouTube 열림), 영상 ID, **배정** / **배정 현황** / **삭제**
  - **배정** 클릭 → 해당 영상 1개만 선택된 상태로 **할당 모달** 열림
  - **배정 현황** 클릭 → **배정 현황(상세) 모달** 열림 (해당 영상이 누구에게 배정되었는지, 진도 등)
  - **삭제** → 해당 영상만 삭제

**등록된 영상 탭일 때**
- 각 영상 행: 체크박스, 제목, **배정** / **배정 현황** / **삭제** (동작은 위와 동일)

---

## 1-3. 반 관리 (`/admin/classes`)

### ① 반별 평균 진도율 (맨 위)
- **반 카드** 클릭 → 해당 반 소속 학생 목록 펼침/접기
- 펼치면: "이 반에 학생 추가" 아래에 다른 반/미소속 학생 목록(체크박스), 선택 후 **선택한 N명 반에 추가** 클릭 → 해당 반에 추가

### ② 반(Class) 관리
- **반 이름** 입력 후 **반 추가** → 새 반 생성
- 기존 반: **수정** 클릭 → 이름 수정 후 **저장** / **취소**, **삭제** 클릭 → 반 삭제

### ③ 반에 영상 일괄 배정 (반이 있고 영상이 있을 때만)
- **재생목록** / **개별 영상** 탭으로 영상 소스 선택
- 재생목록/영상 목록에서 체크 후 **반 선택** 드롭다운에서 반 고르고 **선택한 영상 해당 반에 배정** 클릭 → 그 반 학생들에게 일괄 배정

---

## 1-4. 배정 목록 (`/admin/assign`)

**상단 안내:** 학생별 배정 영상의 진도, 시청 상세, 우선 학습·스킵 방지 설정 확인, 필요 시 배정 해제.

- **학생 이름 검색** 입력 → 학생 필터
- **학생 정렬:** **기본** / **학년별** / **반별** → 목록 정렬

**학생 행**
- **배정된 영상 보기** 클릭 → 해당 학생의 배정 목록 펼침
- 펼치면: **전체** / **완료** / **미완료** / **우선 학습** 필터, 재생목록별로 그룹 표시
  - **이 학생 배정 전체 해제** 클릭 → 확인 후 해당 학생의 모든 배정 해제
  - 재생목록 그룹 옆 **재생목록 전체 해제** 클릭 → 해당 재생목록에 해당하는 배정만 해제
  - 각 배정(영상) 행: 제목, 진도, **우선 학습** 토글, **스킵 방지** 토글, **시청 구간** / **학습 시작** 등 상세 보기, **배정 해제** 클릭 → 그 배정만 해제

# 2. 학생 페이지

**접속 경로:** `/` 또는 `/student` (학생으로 로그인 후 메인 화면)

**상단 공통**
- 로고(학원명), **학습** 탭, **리포트(학부모 보기)** 탭, **비밀번호 변경**·**이메일 등록** 등 계정 관련 링크

---

## 2-1. 학습 탭 (기본 화면)

- **학습** 클릭 → 과제(재생목록·개별 영상) 목록이 보이는 메인 화면

**우선 학습이 있으면**
- **오늘의 미션 · 우선 학습** 섹션에 카드로 표시. 카드 클릭 → 해당 영상 시청 페이지(`/watch/배정ID`)로 이동.

**재생목록·개별 보충 영상**
- **재생목록 카드**(제목, 영상 N개) 클릭 → **재생목록 상세** 페이지(`/student/playlist/재생목록ID`)로 이동
- **개별 보충 영상** 카드 클릭 → 개별 영상만 모아진 목록 페이지로 이동

---

## 2-2. 재생목록 상세 (`/student/playlist/[id]`)

- 상단에 재생목록(또는 "개별 보충 영상") 제목, **← 목록으로** 링크 클릭 → 학생 메인(`/student`)으로 복귀
- 아래에 해당 재생목록(또는 개별 보충)에 속한 **영상 목록** (썸네일, 제목, 진도 %)  
  - **영상 행** 클릭 → 해당 영상 시청 페이지(`/watch/배정ID`)로 이동

---

## 2-3. 영상 시청 (`/watch/[assignmentId]`)

- **제목**, **영상 플레이어**(YouTube 임베드), 하단에 저장된 진도·완료 안내
- **← 목록으로** / **← 목록** 클릭 → 학생 메인으로 복귀
- 영상은 마지막 시청 위치부터 재생되며, 진도는 자동 저장. 스킵 방지가 켜진 배정은 앞으로 건너뛰기가 제한되고, 이미 본 구간으로 되감기는 가능.

---

## 2-4. 리포트(학부모 보기) 탭

- **리포트(학부모 보기)** 클릭 → 학부모용 리포트 화면
- **과제 이수율:** 이번 주(최근 7일)·이번 달(최근 30일) 완료 비율
- **학습 이력 (최근 7일):** 최근 시청 영상별 진도·완료 여부·마지막 시청 시각
- **자동 코멘트** 문구
- (리포트 공유가 켜진 학생 계정으로 들어와야 정상 표시됨)

---

# 3. 강사 페이지

**접속 경로:** `/teacher` (강사로 로그인 후 이동)

**상단 공통**
- **대시보드** → 담당 학생 목록·영상 할당
- **영상 관리** → 재생목록/단일 영상 등록, 담당 학생에게 영상 배정
- **반 관리** → 반별 담당 학생·진도 확인 (관리자가 만든 반 기준)
- **배정 목록** → 담당 학생별 배정 영상 진도·우선학습·스킵방지·배정 해제
- **계정 설정** → 이메일·비밀번호 변경
- **학생 화면** → 학생이 보는 화면(`/`)으로 이동
- **로그아웃**

---

## 3-1. 대시보드 (`/teacher`)

**상단 안내:** 담당 학생만 조회·관리. 학년·반 수정, 영상 배정, 리포트 공유 설정 가능.

### ① 학생 등록
- 이름·초기 비밀번호 입력 후 **등록** → 담당 학생 계정 생성 (관리자 승인 없이 본인 담당으로 연결)

### ② 담당 학생 목록
- **학생 이름 검색** → 목록 필터

**각 학생 한 줄**
- **학년 선택**·**반 선택** 드롭다운
- **영상 할당** 클릭 → 해당 학생 선택. **영상 라이브러리에서 배정할 영상 선택** 클릭 시 등록된 재생목록/영상 목록이 펼쳐짐
  - **재생목록 전체 할당** → 그 재생목록 전체를 해당 학생에게 배정
  - **할당** (영상별) → 그 영상만 해당 학생에게 배정
- **리포트 공유** 토글, **링크 복사** (리포트 URL)

---

## 3-2. 영상 관리 (`/teacher/videos`)

**상단 안내:** 새 영상 등록과 담당 학생에게 배정만 가능. 기존 영상 삭제는 불가.

### ① 재생목록 등록
- **YouTube 재생목록 URL** 입력, **반/재생목록 이름(선택)** 입력 후 **재생목록 등록** 클릭 → 재생목록이 강사용으로 등록됨

### ② 단일 영상 등록 (있을 경우)
- URL·제목 입력 후 영상 등록

### ③ 영상 목록 (재생목록 / 개별 영상 탭)
- **재생목록** 클릭 → 재생목록별로 묶여서 표시. 재생목록 행 클릭 시 해당 재생목록 내 영상 펼침.
- **개별 영상** 클릭 → 재생목록 없는 개별 영상만 표시.
- **제목 검색** 입력 → 목록 필터

**영상이 있을 때 상단**
- **전체 선택** 체크박스
- **선택 항목 학생에게 할당** (1개 이상 선택 시) 클릭 → **할당 모달** 열림  
  - 모달: "선택한 영상을 담당 학생에게 할당", 대상 N개 영상, **학생 이름으로 검색** + 체크박스로 여러 명 선택 후 **할당**

**재생목록 탭**
- 각 재생목록: 체크박스(해당 재생목록 전체 선택), 제목·영상 수, **펼치기** 클릭 → 영상 목록 표시
  - 각 영상: 체크박스, 제목(클릭 시 YouTube), **배정** 클릭 → 해당 영상 1개만 선택된 상태로 **할당 모달** 열림

**개별 영상 탭**
- 각 영상: 체크박스, 제목, **배정** 클릭 → 해당 영상 1개만 선택된 상태로 **할당 모달** 열림

## 3-3. 반 관리 (`/teacher/classes`)

- 관리자가 만든 반 목록과, 각 반에 소속된 **담당 학생**만 표시. 반별 평균 진도 등 확인용.

---

## 3-4. 배정 목록 (`/teacher/assign`)

- **학생 이름 검색**, **학생 정렬(기본/학년별/반별)** 로 담당 학생 목록 필터·정렬
- 각 학생 **배정된 영상 보기** 클릭 → 해당 학생의 배정 목록 펼침
  - 재생목록별 그룹, 진도, **우선 학습**·**스킵 방지** 토글, **배정 해제** 등 (관리자 배정 목록과 유사하되 담당 학생만 대상)

---

## 3-5. 계정 설정 (`/teacher/settings`)

- **이메일** 입력 후 저장 → 비밀번호 찾기용 이메일 등록
- **비밀번호**·**비밀번호 확인** 입력 후 **비밀번호 변경** → 로그인 비밀번호 변경
